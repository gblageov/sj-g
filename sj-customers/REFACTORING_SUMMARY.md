# Рефакториране - Обобщение

## Дата: 5 ноември 2025

## Причина
Файлът `customer_validator.py` беше прекалено голям (500+ реда) и трудно се поддържа. Разделен е на отделни модули за лесна поддръжка и разширяване.

## Структура преди

```
processing/
└── customer_validator.py  (500+ реда)
```

## Структура след

```
processing/
├── customer_validator.py      # Главен модул (180 реда)
├── order_processor.py          # Обработка на поръчки (130 реда)
├── field_validators.py         # Валидация на полета (220 реда)
└── file_handler.py             # Файлови операции (170 реда)
```

## Промени по модули

### 1. `customer_validator.py` (Главен модул)
**Отговорност**: Оркестриране на целия процес
**Функции**:
- `process_customer_file()` - главна функция

**Стъпки**:
1. Чете Excel файл
2. Нормализира данни
3. Обработва поръчки (Top Row)
4. Обрязва по празен Name
5. Валидира и попълва полета
6. Добавя тагове
7. Записва резултат
8. Генерира отчет

### 2. `order_processor.py` (Нов модул)
**Отговорност**: Логика за групиране и пренасяне на данни по поръчки
**Функции**:
- `get_order_groups(df)` - Намира и групира поръчки по Top Row и Name
- `propagate_order_data(df, order_groups)` - Пренася данни от Top Row към артикулни редове

**Специална логика**:
- Извлича телефон от която и да е телефонна колона на Top Row
- Пренася телефон към празните стандартни телефонни полета в групата
- Пренася всички клиентски данни (имена, адреси, държави и т.н.)

### 3. `field_validators.py` (Нов модул)
**Отговорност**: Валидация и попълване на полета
**Функции**:
- `validate_email_field()` - Email валидация
- `validate_phone_fields()` - Телефонна валидация с кръстосана проверка
- `validate_name_fields()` - Валидация на имена
- `validate_address_fields()` - Валидация на адреси
- `validate_city_fields()` - Валидация на градове
- `validate_country_fields()` - Валидация на държави
- `process_all_fields()` - Обработва всички полета
- `add_judgeme_tag()` - Добавя таг
- `get_existing_required_columns()` - Проверява кои задължителни колони съществуват

**Константи**:
```python
DEFAULT_EMAIL = 'shopify@getnada.com'
DEFAULT_PHONE = '+1234567890'
DEFAULT_TEXT_VALUE = 'Shopify'
DEFAULT_COUNTRY = 'Bulgaria'
DEFAULT_COUNTRY_CODE = 'BG'
REQUIRED_FIELDS = [...]  # Списък на задължителните полета
```

### 4. `file_handler.py` (Нов модул)
**Отговорност**: Четене и запис на Excel файлове
**Функции**:
- `read_excel_file()` - Чете с опазване на данните (dtype=str, keep_default_na=False)
- `normalize_dataframe()` - Нормализира TRUE/FALSE и Command колона
- `truncate_by_empty_name()` - Обрязва по празен Name
- `save_excel_file()` - Записва всички листове
- `print_column_statistics()` - Показва статистики
- `print_summary_report()` - Генерира обобщаващ отчет

```python
def validate_new_field(df: pd.DataFrame, col: str) -> pd.DataFrame:
    """Validate and fill new field."""
    # Вашата логика тук
    return df
```

### Промяна на стойност по подразбиране
Редактирайте само константите в `field_validators.py`:
