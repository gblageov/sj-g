# Инструкции за използване на Shopify Customer Data Validator

## Създадена програма

В директория `sj-g/sj-customers` е създадена нова програма за валидация и поправка на клиентски данни за Shopify.

## Структура на проекта

```
sj-customers/
├── gui.py                      # Графичен интерфейс (идентичен със съществуващия)
├── run.py                      # Главен стартов файл
├── run_customers.bat           # Batch файл за лесно стартиране (Windows)
├── test_validator.py           # Тестов скрипт
├── README.md                   # Документация (английски)
├── ИНСТРУКЦИИ.md              # Този файл с инструкции
└── processing/
    ├── __init__.py
    └── customer_validator.py   # Основна логика за обработка
```

## Как работи програмата

### 1. Стартиране
- **Чрез batch файл**: Двойно кликване върху `run_customers.bat`
- **Чрез Python**: `python run.py` в директорията на програмата

### 2. Графичен интерфейс
- Интерфейсът е идентичен със съществуващата програма
- Поле за избор на входен XLSX файл
- Бутон "Validate & Fix Data" за стартиране на обработката
- Конзолен прозорец за обратна връзка

### 3. Обработка на данните
Програмата проверява следните задължителни полета за Shopify:

**Customer:**
- Customer: Email

**Billing:**
- Billing: First Name
- Billing: Last Name  
- Billing: Phone
- Billing: Address 1
- Billing: Country Code (приоритет) или Billing: Country

**Shipping:**
- Shipping: First Name
- Shipping: Last Name
- Shipping: Phone
- Shipping: Address 1
- Shipping: City
- Shipping: Country Code

### 4. Поправка на липсващи данни
- **Телефонни полета** (`Shipping: Phone`, `Billing: Phone`): попълват се с "+1234567890"
- **Всички останали полета**: попълват се с "Shopify"

### 5. Изходни файлове
- **Excel файл**: Поправените данни с име `[оригинално_име]_[ГГГГММДД_ЧЧММСС].xlsx`
- **Текст файл**: Лог на обработката с име `[оригинално_име]_[ГГГГММДД_ЧЧММСС].txt`

## Примерна работа

1. Стартирайте програмата с `run_customers.bat`
2. Натиснете "Browse..." и изберете вашия XLSX файл
3. Натиснете "Validate & Fix Data"
4. Изчакайте обработката и вижте отчета в конзолата
5. Намерете изходните файлове в същата директория като входния файл

## Изисквания

- Python 3.7+
- pandas
- openpyxl

Ако липсват, batch файлът ще се опита да ги инсталира автоматично.

## Тест

За тестване на програмата:
```bash
python test_validator.py
```

Това ще създаде тестов файл, ще го обработи и ще покаже резултатите.
