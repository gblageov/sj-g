# WooCommerce към Shopify — Свързване на продукти (с графичен интерфейс)

Този проект съдържа Python програма с графичен интерфейс за обработка на продуктови експорти от WooCommerce (в `.xlsx` формат). Основната цел е да се прочетат данни за свързани продукти (bundled products) от мета поле на WooCommerce, да се намерят съответстващите им продукти в същия файл по SKU или ID и да се попълни мета поле с техните „Handle“ стойности, готово за импорт в Shopify.

## 🖥️ Нови функции

- **Графичен потребителски интерфейс** с бутони за избор на файл и стартиране на обработката
- **Автоматично запазване** на резултатите в нов Excel файл с добавен timestamp
- **Детайлен лог** на процеса в текстов файл
- **Опростен процес на инсталация** с помощен batch файл
- **Интегрирана конзола** за проследяване на процеса
- **Автоматично актуализиране на типове** чрез `new-types.json` за преименуване на съществуващи типове продукти
- **Генериране на отчет** с детайлна статистика за всички типове продукти
- **Подобрена обработка на листа 'Products'** с автоматично поправяне на имената на листовете
- **Оптимизирани операции** с данни за по-бърза обработка на големи файлове

### Стъпка 2: Настройка на виртуална среда и инсталиране на зависимости

Използването на виртуална среда (`venv`) е силно препоръчително, за да се изолират пакетите на проекта от глобалната инсталация на Python.

#### 🐧 **На Linux / macOS**

1. **Отворете терминал** и навигирайте до папката на проекта.
2. **Създайте виртуална среда** с име `env`:

   ```bash
   python3 -m venv env
   ```
3. **Активирайте средата:**

   ```bash
   source env/bin/activate
   source env/bin/activate.fish
   ```

   След активиране, името на средата (`env`) ще се появи в началото на командния ред.
4. **Инсталирайте необходимите пакети** от `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

#### 💻 **На Windows**

1. **Отворете Command Prompt** или **PowerShell** и навигирайте до папката на проекта.
2. **Създайте виртуална среда** с име `env`:

   ```bash
   python -m venv env
   ```
3. **Активирайте средата:**

   ```powershell
   .\env\Scripts\activate
   ```

   След активиране, името на средата (`env`) ще се появи в началото на командния ред.
4. **Инсталирайте необходимите пакети** от `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

> **Забележка:** Когато приключите работа, можете да деактивирате виртуалната среда, като просто напишете командата:
>
> ```bash
> deactivate
> ```

## ▶️ Как да използваме програмата

1. **Подгответе файла:**
   По подразбиране програмата очаква `import_result.xlsx` в същата папка като `run.py`.

2. **Активирайте виртуалната среда** (ако не е вече активна), както е описано в стъпка 2.

3. **Стартирайте програмата** от терминала (в папката на проекта):

   - Без параметри (използва `import_result.xlsx`):
     ```bash
     python run.py
     ```
   - С конкретен входен файл:
     ```bash
     python run.py -i d:\path\to\your.xlsx
     ```

4. **Резултат:**
   Програмата ще обработи файла и ще създаде нов файл с шаблон на име:
   
   ```
   <original_name>_updated_YYYYMMDD-HHMM.xlsx
   ```
   
   Данните са записани в лист `Products`, като колона `Type` е попълнена автоматично, а `Metafield: global.Combined handle` съдържа свързаните handle-ове.

## 🆕 Нови функции в детайли

### 🔄 Автоматично актуализиране на типове чрез `new-types.json`

Програмата вече поддържа файл `new-types.json` в основната директория, който позволява лесно преименуване на типове продукти. Файлът трябва да съдържа списък от обекти с полета:
- `Type` - текущото име на типа
- `New Type` - новото име, на което да бъде сменен типа

**Пример:**
```json
[
  {
    "Type": "Гривна",
    "New Type": "Гривни"
  },
  {
    "Type": "Обеца",
    "New Type": "Обеци"
  }
]
```

### 📊 Генериране на отчет за типове продукти

След обработката на файла, програмата създава допълнителен отчет в Excel формат с информация за:
- Всички уникални типове продукти
- Брой продукти от всеки тип
- Процентно разпределение
- Топ 10 най-често срещани типове

### 🛠️ Подобрена обработка на данни

- **Оптимизирани операции** с DataFrame за по-бърза обработка на големи файлове
- **Автоматично поправяне** на имената на листовете, за да се гарантира, че винаги има лист с име точно 'Products'
- **Подобрено логване** на промените в типовете продукти

## 🐞 Бележки и дебъг

- **Съобщенията в конзолата** описват всяка стъпка (прочитане, попълване на `Type`, изграждане на речници, обработка на `Combined handle`, запис и обобщение).
- Ако видите грешка `PermissionError` при запис, уверете се, че изходният `.xlsx` не е отворен в Excel/Viewer и че няма lock файл (например `.~lock.*`).
- Предупреждение на pandas относно dtype на `Type` може да се появи; обработката продължава нормално. При необходимост колоната може да се кастне към `object` вътрешно.

За допълнително логване/диагностика може да се добавят помощни проверки в модулите в `processing/`, без да се променя входната точка.
